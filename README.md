# KkthnxUI

[![Last Commit](https://img.shields.io/github/last-commit/Kkthnx-Wow/KkthnxUI/master)](https://github.com/Kkthnx-Wow/KkthnxUI/commits/master) [![Issues](https://img.shields.io/github/issues/Kkthnx-Wow/KkthnxUI)](https://github.com/Kkthnx-Wow/KkthnxUI/issues) [![Download](https://img.shields.io/badge/CurseForge-Download-orange)](https://www.curseforge.com/wow/addons/kkthnxui)

KkthnxUI is a clean, lightweight interface replacement for World of Warcraft that rebuilds the default UI into one consistent look.

## What it does

- Rebuilds unit frames, nameplates, and castbars in a single clean style
- Adds tidy action bars with cooldown numbers and a square minimap
- Replaces the bag UI, cleans up chat, enriches tooltips, and tweaks the world map
- Ships one in game options panel for everything, opened with `/kk`
- Runs on both Retail and Classic

## Get it

Download from [CurseForge](https://www.curseforge.com/wow/addons/kkthnxui), or drop this repository into your `Interface/AddOns` folder.

## Quick start

1. Install KkthnxUI through CurseForge or copy the folder into `Interface/AddOns`.
2. Log in and type `/kk` to open the options panel.
3. Type `/kk move` to unlock the movers, then drag frames where you want them.
