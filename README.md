# KkthnxUI

[![Last Commit](https://img.shields.io/github/last-commit/Kkthnx-Wow/KkthnxUI/master)](https://github.com/Kkthnx-Wow/KkthnxUI/commits/master) [![Issues](https://img.shields.io/github/issues/Kkthnx-Wow/KkthnxUI)](https://github.com/Kkthnx-Wow/KkthnxUI/issues) [![Download](https://img.shields.io/badge/CurseForge-Download-orange)](https://www.curseforge.com/wow/addons/kkthnxui)

KkthnxUI is a clean, lightweight interface replacement for World of Warcraft. It
rebuilds the default UI from the ground up into one consistent look, so every
class and role gets a tidy, readable setup right out of the box.

## What you get

- Unit frames, nameplates, and castbars in a single clean style
- Action bars, cooldown numbers, and a square minimap that stay out of your way
- A bag replacement, chat cleanup, richer tooltips, and world map tweaks
- One in game options panel for all of it, opened with `/kk`

## Install

Download it from [CurseForge](https://www.curseforge.com/wow/addons/kkthnxui),
or drop this repository into your `Interface/AddOns` folder.

Available for Retail and Classic.

## Options

Type `/kk` in game to open the options panel. `/kk move` unlocks the movers so you
can drag frames where you want them.
